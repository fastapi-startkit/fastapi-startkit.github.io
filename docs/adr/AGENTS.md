# Architectural Decision Records

| Date | Record | Decision |
|---|---|---|
| 2026-10-31 | [Database: Getting Started page](2026-10-31-database-getting-started.md) | The Database overview page now follows Laravel's "Database: Getting Started" and keeps only what framework `main` supports: supported databases, drivers and extras; `artisan db:install --driver=...` as the primary setup path (install extras first; it doesn't edit `.env`), with manual setup kept as an alternative and the broken-for-new-apps `provider:publish --provider=database` removed; connection options and env vars; SQLite files and `:memory:`; URLs with the shared `DB_URL` pitfall; pool tuning through `engine_options()`; raw SQL; multiple connections; `echo` query logging; and the transactions section (savepoints, `after_commit`, test mixins, and SQLite deferred-`BEGIN` warnings). Laravel features the framework lacks are reported as gaps, not documented. All examples were verified on SQLite, Postgres 17, and MySQL 8. |
| 2026-10-21 | [Getting started leads with `uvx fastapi-startkit init`](2026-10-21-uvx-init-getting-started.md) | Getting Started opens with "Creating a Project" (install uv, `uvx fastapi-startkit init my-app`, the three questions, an options table) verified against a real 0.67.0 run; manual setup kept below as an alternative; home install pill and steps use the installer and `uv run`; the hosted `install.sh` one-liner is listed alongside `uvx` for macOS/Linux. |
| 2026-10-19 | [Hosted install script](2026-10-19-install-script.md) | `public/install.sh` is served at `https://fastapi-startkit.github.io/install.sh`; it finds or installs uv (official installer, absolute path so no terminal restart), then runs `uv tool run fastapi-startkit@latest init` with forwarded arguments and `/dev/tty` input; `FASTAPI_STARTKIT_VERSION` pins a release; macOS/Linux only. |
| 2026-10-15 | [Home page uses Instrument Sans](2026-10-15-home-instrument-sans.md) | Home page tokens (`--hp-sans`) point at `--site-sans`, so the home header and sections use Instrument Sans like the docs; serif accents and mono labels unchanged. |
